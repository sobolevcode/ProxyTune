# ProxyTune for webOS (English)

ProxyTune is an advanced multi-protocol VPN client designed specifically for rooted LG smart TVs running webOS. It provides seamless access to global content and bypasses network restrictions directly on your TV.

## Key Features

* **Dual Network Engines:** Native support for Xray (VLESS, Reality, Trojan) and AmneziaWG protocols.
* **Mobile Web Control:** Fully manage connections, servers, and subscriptions via a responsive web interface from your smartphone.
* **High Performance:** Direct routing via kernel TUN interface ensures minimal CPU and RAM consumption on the TV.
* **Smart Parsing:** Automatic recognition of configuration links and subscription updates.
* **System Diagnostics:** Built-in log viewer for easy troubleshooting and connection monitoring.

## Requirements
* LG smart TV running webOS.
* Root access.
* Homebrew Channel installed.

## Installation
**Recommended:** Install directly through our official repository.
1. Open Homebrew Channel on your TV.
2. Go to Settings -> Repositories -> Add Repository.
3. Enter our catalog link: `https://sobolevcode.github.io/repo.json`
4. Install and update ProxyTune directly from the store.

**Manual:** Download the latest `.ipk` file from the [Releases](https://github.com/sobolevcode/ProxyTune/releases) section and install it via webOS Dev Manager.

# ProxyTune для webOS (Русский)

ProxyTune — это продвинутый мультипротокольный VPN-клиент, созданный специально для смарт-телевизоров LG на базе webOS. Обеспечивает комфортный доступ к глобальному контенту и обход сетевых ограничений прямо на уровне системы ТВ.

## Основные возможности

* **Два независимых ядра:** Нативная поддержка современных протоколов Xray (VLESS, Reality, Trojan) и AmneziaWG.
* **Мобильный пульт:** Управление подключениями, серверами и подписками через удобный локальный веб-интерфейс с вашего смартфона.
* **Высокая производительность:** Прямая маршрутизация трафика через TUN-интерфейс ядра с минимальным потреблением памяти и процессора ТВ.
* **Умный парсинг:** Автоматическое распознавание ссылок на конфигурации и поддержка автообновления подписок.
* **Системная диагностика:** Встроенный просмотрщик логов для удобной отладки и мониторинга состояния туннеля.

## Системные требования
* Телевизор LG на базе webOS.
* Наличие Root-прав.
* Установленный Homebrew Channel.

## Установка
**Рекомендуемый способ:** Установка через официальный каталог.
1. Откройте Homebrew Channel на телевизоре.
2. Перейдите в Настройки (Settings) -> Репозитории (Repositories) -> Add Repository.
3. Введите адрес: `https://sobolevcode.github.io/repo.json`
4. Устанавливайте и обновляйте ProxyTune прямо из магазина.

**Вручную:** Скачайте актуальный `.ipk` файл в разделе [Releases](https://github.com/sobolevcode/ProxyTune/releases) и установите через webOS Dev Manager.
